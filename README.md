# Portfolio Dashboard

Modern personal developer portfolio built with pure HTML, CSS and JavaScript.

## Run in Acode
1. Extract this ZIP.
2. Open the `portfolio-dashboard` folder in Acode.
3. Open `index.html`.
4. Use Acode Preview.

## Main files
- `index.html` — structure/content
- `css/style.css` — complete UI and animations
- `js/script.js` — interactions and animations
- `assets/` — place personal images here
